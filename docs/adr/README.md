# Architecture decisions

One file per decision, named `NNNN-a-sentence-in-lower-case.md`. The number is permanent: a decision
that is later reversed keeps its number and gains a **Superseded by** line, so a citation in an old
page still resolves.

These records were kept privately while the product was hosted. They are published here because the
public docs cite them and a reader could not follow the citations.

## Numbers that have no record

Two kinds of gap, both deliberate:

- **Never written or removed before publication.** `0013` is cited as a planned split that was never
  decided, and `0036` named a surface that was removed before this archive was published. A citation
  says so in the prose; there is no file to find.
- **Withdrawn with the hosted tier.** `0075`, `0076`, `0077`, `0078`, `0081`, `0083`, `0084` and
  `0099` proposed entitlements, billing, open sign-up, and a hosted daemon. Those were in `proposed`
  when the product stopped being hosted, so they were withdrawn rather than accepted. A page that
  cites one is describing something that does not exist and should be rewritten or removed.
