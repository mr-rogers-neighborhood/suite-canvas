---
title: A way back in
description: "The file that makes a new machine this device again, and why the hub cannot do it for you."
order: 30
---

The machine that shares a workspace carries it; it cannot read it, so it cannot restore it. If every
device in a workspace is lost, the workspace is gone. One file changes that.

**A way back in** is offered once, in the Sync dialog, right after a workspace becomes shared. It
holds two things: this device's identity, which is the key the machine sharing the workspace knows it
by, and this device's place in the workspace. Save it somewhere you trust — the same folder you back
up, or a drive you keep.

- **A passphrase is optional.** Add one if the file will travel somewhere you do not control; leave it
  out if it stays where you keep your own things. Without one, whoever opens the file becomes this
  device.
- **Declining is remembered.** *Not now* answers the question, so the dialog stops asking. Nothing
  breaks — the offer just stops appearing.
- **Restoring is the other half.** On a machine that has never joined this workspace, open the Sync
  dialog and choose *I have a recovery file*. The machine takes on this device's identity and rejoins
  where it left off.

A recovery file is a device, not a copy of your work. It cannot be shared between two machines, and it
cannot bring back what happened before it was written: open the document you still have, and the
workspace catches up from there.
